## 2. Pengantar Web Mining

**Web Mining** adalah proses penerapan teknik data mining untuk menemukan pola, informasi, dan pengetahuan yang berguna dari data yang ada di internet (web). Karena data di web sangat besar, beragam, dan tidak terstruktur, web mining membantu mengekstrak informasi bermakna secara otomatis dari sumber tersebut.

Secara umum, web mining dibagi menjadi tiga kategori:

1. **Web Content Mining** – menggali informasi dari isi halaman web, seperti teks, gambar, video, atau data lainnya. Contoh: analisis sentimen dari review produk.
2. **Web Structure Mining** – menganalisis struktur hubungan antar halaman web (link antar situs), misalnya digunakan Google untuk menentukan peringkat halaman (PageRank).
3. **Web Usage Mining** – mempelajari pola perilaku pengguna saat mengakses web, misalnya melalui log server, untuk memahami kebiasaan pengunjung.

Web mining banyak dimanfaatkan dalam berbagai bidang, antara lain:

- **E-commerce** – sistem rekomendasi produk berdasarkan perilaku pembeli.
- **Mesin pencari** – meningkatkan relevansi hasil pencarian.
- **Deteksi spam** – mengenali pola konten yang tidak diinginkan.
- **Analisis media sosial** – memahami tren dan opini publik.
